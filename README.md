# ☕ Java Fundamentals & Practice Repository

This repository contains Java exercises, examples, and concepts developed as part of my learning path in **Java programming**.  
It focuses on core language fundamentals, object-oriented programming, and practical problem-solving, with a mindset aligned to **software quality and good development practices**.

The content reflects hands-on practice, iteration, and continuous improvement rather than copy-paste examples.

---

## 🎯 Purpose of This Repository

- Strengthen Java fundamentals
- Understand Object-Oriented Programming (OOP) concepts
- Practice clean, readable, and maintainable code
- Build a solid base for backend development and QA automation
- Serve as reference material for future projects

---

## 🛠️ Technologies Used

- **Java (JDK 8+)**
- **IDE:** IntelliJ IDEA / Eclipse / VS Code (Java extensions)
- **Build tools:** Basic Java execution (no framework dependency)
- **Version control:** Git & GitHub
